# Security policy

## Supported versions

Security fixes are applied to the latest version on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, leaked credential, or privacy issue. Use GitHub's private vulnerability reporting for this repository if available. If it is not available, contact the repository owner privately through GitHub with a concise description, affected files or endpoints, reproduction steps, and any suggested mitigation.

Do not include real API keys or personal data in a report. We will acknowledge a report as soon as practical and work with you on disclosure after a fix is available.
